# Dex

Мобильный обозреватель иерархии Roblox-плейса: дерево `Workspace` с ленивой
подгрузкой, подсветка выбранного объекта в 3D и панель с его свойствами
коллизии.

Один файл, чистый Luau, только официальный Roblox API — никаких
executor-функций (`hookmetamethod`, `firetouchinterest`, `getgenv` и т.п.),
хотя сам файл запускается через executor.

## Запуск (телефон и ПК одинаково)

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/hoykoS/Dex/main/Dex.lua"))()
```

Панель открывается сразу — никакой настройки не требуется.

## Установка как LocalScript в свой плейс

Тот же файл можно вставить внутрь **своего** плейса как обычный скрипт, если
хочешь, чтобы панель реплицировалась игрокам без loadstring:

1. Открой свой плейс в Roblox Studio.
2. `StarterPlayer → StarterPlayerScripts` → правый клик → `Insert Object` →
   **LocalScript**.
3. Вставь содержимое `Dex.lua` в этот скрипт.
4. Publish — панель появится у всех при заходе в игру.

По умолчанию в этом режиме она тоже открыта всем. Если нужно ограничить круг
пользователей (например, чтобы обычные игроки её не увидели), впиши свои
`UserId` в `CONFIG.Admins` — тогда доступ получат только они, владелец
плейса и ты в Studio:

```lua
CONFIG.Admins = { 123456789 }
```

## Что умеет

- Плавающая кнопка **Dex** в углу экрана открывает окно; кнопку можно
  перетащить, если она мешает.
- Дерево `Workspace` вверху окна: тап по стрелке ▶ разворачивает
  папку/модель — дети подгружаются лениво, при первом разворачивании, чтобы
  большие плейсы не тормозили.
- Тап по имени объекта подсвечивает его в мире (`Highlight`) и показывает
  внизу его класс, полный путь и параметры коллизии: `CanCollide`,
  `CanTouch`, `CanQuery`, `CollisionGroup`, `CollisionFidelity` (для мешей и
  юнионов), `Size`.
- Кнопка **⟳** в шапке пересобирает дерево с нуля — полезно, если объекты в
  мире появились или исчезли после открытия панели.
- Окно появляется по центру экрана и тянется за шапку в любое место.
- Значок **⤡** в правом нижнем углу окна — тяни от центра наружу, чтобы
  увеличить панель, к центру — чтобы уменьшить (масштаб 0.7×–1.6×).

## Про режим "вставить в плейс"

В этом режиме скрипт физически лежит внутри `StarterPlayerScripts` твоего
плейса и реплицируется каждому клиенту автоматически при заходе в игру,
включая телефон — без `loadstring`, `getgenv` и инжектов. Это удобно, если
хочешь, чтобы панель была встроена в саму игру, а не запускалась вручную
каждый раз через executor.
