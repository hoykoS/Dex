# Dex

Мобильный обозреватель иерархии Roblox-плейса: полное дерево `DataModel`
(все сервисы, не только `Workspace`), поиск по имени, подсветка выбранного
объекта в 3D и панель с его свойствами коллизии — плюс режим "Выбрать",
который сворачивает панель и находит объект в дереве по тапу прямо в игровом
мире.

Один файл, чистый Luau, только официальный Roblox API — никаких
executor-функций (`hookmetamethod`, `firetouchinterest`, `getgenv` и т.п.),
хотя сам файл запускается через executor.

## Запуск (телефон и ПК одинаково)

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/hoykoS/Dex/main/Dex.lua"))()
```

Панель открывается сразу — никакой настройки не требуется.

## Установка как LocalScript в свой плейс

Тот же файл можно вставить внутрь **своего** плейса как обычный скрипт, если
хочешь, чтобы панель реплицировалась игрокам без loadstring:

1. Открой свой плейс в Roblox Studio.
2. `StarterPlayer → StarterPlayerScripts` → правый клик → `Insert Object` →
   **LocalScript**.
3. Вставь содержимое `Dex.lua` в этот скрипт.
4. Publish — панель появится у всех при заходе в игру.

По умолчанию в этом режиме она тоже открыта всем. Если нужно ограничить круг
пользователей (например, чтобы обычные игроки её не увидели), впиши свои
`UserId` в `CONFIG.Admins` — тогда доступ получат только они, владелец
плейса и ты в Studio:

```lua
CONFIG.Admins = { 123456789 }
```

## Что умеет

Окно разбито на три вкладки в шапке: **Дерево**, **Выбрать**, **Настройки UI**.
Плавающая кнопка **Dex** в углу экрана открывает и закрывает окно; кнопку
можно перетащить, если она мешает. Окно тянется за шапку в любое место, а
значок в правом нижнем углу — за него меняется масштаб (0.7×–1.6×).

### Дерево

- Показывает весь `DataModel`, а не только `Workspace` — все сервисы
  (`Workspace`, `Players`, `Lighting`, `ReplicatedStorage` и так далее) сразу
  видны как папки верхнего уровня.
- Тап по `+` разворачивает папку/модель — дети подгружаются лениво, при
  первом разворачивании, чтобы большие плейсы не тормозили.
- Поиск по имени вверху дерева: находит совпадения по всему `DataModel`
  (до 200 штук), тап по результату сворачивает список обратно и раскрывает
  дерево ровно до найденного объекта.
- Кнопки **Развернуть всё** / **Свернуть всё** для быстрой навигации,
  **Обновить** — пересобирает дерево с нуля.
- Тап по имени объекта подсвечивает его в мире (`Highlight`) и показывает
  внизу его класс, полный путь, родителя, число детей и параметры коллизии:
  `CanCollide`, `CanTouch`, `CanQuery`, `CollisionGroup`, `CollisionFidelity`
  (для мешей и юнионов), `Size`, `Material`, `Anchored`.
- Цветные точки слева от имени — класс объекта (модель, часть, скрипт,
  папка и т.п.), можно выключить во вкладке Настройки UI.

### Выбрать

Нажимаешь **Выбрать объект в игре** — панель сворачивается, остаётся только
маленькая плашка-подсказка с кнопкой **Отмена**. Камеру можно свободно
вращать и двигать персонажа — сработает только короткий тап без сдвига
пальца. Тап по любому объекту в 3D-мире раскрывает панель обратно на вкладке
Дерево, автоматически разворачивая все папки на пути к этому объекту и
подсвечивая его.

### Настройки UI

- Слайдер масштаба интерфейса (то же самое, что и щипок за уголок окна, но
  точнее).
- Компактные строки дерева (меньше высота строки, больше влезает на экран).
- Вкл/выкл цветных точек-классов.
- Кнопка сброса окна в исходные позицию и размер.

## Про режим "вставить в плейс"

В этом режиме скрипт физически лежит внутри `StarterPlayerScripts` твоего
плейса и реплицируется каждому клиенту автоматически при заходе в игру,
включая телефон — без `loadstring`, `getgenv` и инжектов. Это удобно, если
хочешь, чтобы панель была встроена в саму игру, а не запускалась вручную
каждый раз через executor.
